# nore-prompter

Home of Peter the Prompter, NORE Jewellery's prompt writer. Kept apart from the other agents'
folders, each with its own memory.

- `CLAUDE.md` — Peter's role, limits, business facts and commands (draft; owner finishes it with Peter).
- `prompt-rules.md` — "Prompt Rules" memory.
- `prompt-wins-flops.md` — "Prompt Wins & Flops" memory.
- `prompt-library.md` — "Prompt Library" memory (approved prompts, ready to reuse).

Peter reads the three memory files at the start of every chat. He writes prompts but never
applies them in another agent's folder or a live tool, and never posts, sends or spends without
the owner's approval. Items marked `[TODO: ...]` are waiting on the owner.
