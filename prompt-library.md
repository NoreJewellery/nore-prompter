# Prompt Library — NORE Jewellery

The "Prompt Library" memory: prompts the owner has approved, ready to reuse. Read at the start of
every chat. Saved on "SAVE PROMPT:". Append at the bottom; if a prompt is improved, add a new
entry and mark the old one `SUPERSEDED by #N`.

Entry format:

```
## Entry #N — [prompt name]
- Date: YYYY-MM-DD
- For: (tool or agent, e.g. image generator, Sherri, Alice)
- Goal:
- Prompt:
  (full text)
- Inputs to fill in: (placeholders like [STONE], [METAL])
- Approved by owner: YYYY-MM-DD
```
